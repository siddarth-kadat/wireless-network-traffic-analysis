# Database Schema Design

## Updated 7-Entity Database Design

The database schema has been updated to include seven core entities, introducing the `User` entity for role-based authentication and authorization.

### Entities Summary

1. **User**
   - Attributes: `user_id` (PK), `username`, `password_hash`, `role`
   - Cardinality: `User (1) -> Log_Batch (N)`

2. **Log_Batch**
   - Attributes: `batch_id` (PK), `user_id` (FK), `file_name`, `file_format`, `submitted_at`, `processing_status`, `total_records`, `processed_records`, `failed_records`
   - Relationships: Belongs to `User`; has many `Traffic_Log` records; has many `Processing_Error` records.

3. **Traffic_Log**
   - Attributes: `log_id` (PK), `batch_id` (FK), `timestamp`, `source_address`, `destination_address`, `source_mac`, `destination_mac`, `protocol`, `log_details`
   - Relationships: Belongs to `Log_Batch`; has many `Detection_Result` records; associated with `Processing_Error` where applicable.

4. **Detection_Rule**
   - Attributes: `rule_id` (PK), `rule_name`, `suspicious_activity`, `protocol`, `detection_condition`, `threshold_value`, `time_window_seconds`, `severity`, `is_enabled`
   - Relationships: Matches many `Detection_Result` records.

5. **Detection_Result**
   - Attributes: `result_id` (PK), `log_id` (FK), `rule_id` (FK), `rule_match_status`, `observed_value`, `threshold_value`, `detection_evidence`, `detection_time`
   - Relationships: Refers to `Traffic_Log`; refers to `Detection_Rule`; generates zero or one `Alert`.

6. **Alert**
   - Attributes: `alert_id` (PK), `result_id` (FK), `alert_details`, `alert_timestamp`, `severity`, `alert_status`
   - Relationships: Generated by one `Detection_Result`.

7. **Processing_Error**
   - Attributes: `error_id` (PK), `batch_id` (FK), `log_id` (FK, nullable), `error_type`, `error_message`, `error_timestamp`
   - Relationships: Associated with `Log_Batch` and optionally `Traffic_Log`.

---

## Schema Update & Handbook Conflict Notice

- **Sprint 1 Handbook Initial Design**: The preliminary handbook recorded a condensed 3-table schema (`Traffic_Log`, `Detection_Result`, `Alert`) or 6-table schema without user role authentication.
- **Approved Update**: The approved architecture integrates the `User` entity and formalizes `Log_Batch` and `Processing_Error` tracking, establishing a complete 7-entity relational schema managed exclusively through Engine E3 (`Log and Alert Storage Engine`).
